# PocketSmart AI

PocketSmart AI is a complete AI-powered budget and recommendation assistant.

## Features

- User registration
- Login/logout
- JWT authentication
- SQLite database
- Home Interior Planner
- Party Planner
- Jewelry Planner
- Optional outfit image upload
- Gemini AI integration
- Local fallback recommendation engine
- Recommendation history
- FastAPI Swagger documentation
- Automated tests
- Responsive frontend

## Requirements

Install:

- Python 3.11+
- VS Code
- Gemini API key (optional)
